# Time Tracking Dashboard

A time-tracking dashboard built with React, based on the Frontend Mentor challenge. A profile card lets you switch between Daily, Weekly and Monthly reports, and six activity cards (Work, Play, Study, Exercise, Social, Self Care) show the current and previous hours for the selected period from a local data file.

## Tech
- React 18 (Create React App)
- React Router
- Plain CSS

## Run locally
npm install
npm start
Then open http://localhost:3000.

## What I practised
- Rendering lists from a data file with map
- Switching UI state with useState (daily / weekly / monthly)
- Styling components with plain CSS
